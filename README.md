# Sistema de Eventos

Um sistema web para gerenciamento de eventos, desenvolvido em **Node.js**, **MySQL**, **HTML** e **CSS**.  
O objetivo é facilitar o cadastro, controle e visualização de eventos, participantes e inscrições.

---

##  Tecnologias Utilizadas

- **Node.js** – Back-end da aplicação  
- **Express** – Framework para criar rotas e APIs  
- **MySQL** – Banco de dados relacional  
- **HTML / CSS** – Interface simples e funcional  
- **JavaScript** – Lógica e interatividade no front-end  

---

## ⚙️ Funcionalidades (até agora)

- Cadastro de usuários  
- Login e autenticação  
- CRUD de eventos (criar, listar, editar e excluir)  
- Cadastro e listagem de participantes  
- Sistema de busca e filtros
